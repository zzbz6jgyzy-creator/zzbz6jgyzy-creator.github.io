# Earth imagery and processing

The globe uses historical satellite composites as texture maps with lighting and
animation rendered by this website. It is not a current photograph, live cloud
feed or a view from a spacecraft. Cloud motion is an artistic animation.

## Day surface — NASA Blue Marble: Next Generation

- Primary source page: <https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/base-map/>
- July 2004 composite master (21600×10800): <https://assets.science.nasa.gov/content/dam/science/esd/eo/images/bmng/bmng-base/july/world.200407.3x21600x10800.jpg>
- Credit: NASA Earth Observatory; Reto Stöckli, NASA Goddard Space Flight Center.
- Deliveries: 2048×1024, 4096×2048 and 8192×4096 WebP. The 8K tier is derived from the real 21600-pixel master, with no upscaling.
- Processing: Lanczos downsampling and WebP compression. The base map has no clouds or directional lighting baked in. The browser adds those separately.

## Night lights — NASA Black Marble 2016

- Primary source page: <https://science.nasa.gov/earth/earth-observatory/earth-at-night/maps/>
- Master (13500×6750): <https://assets.science.nasa.gov/content/dam/science/esd/eo/images/imagerecords/144000/144898/BlackMarble_2016_3km.jpg>
- Credit: NASA Earth Observatory images by Joshua Stevens, using Suomi NPP VIIRS data from Miguel Román, NASA Goddard Space Flight Center.
- Deliveries: 2048×1024 and 4096×2048 WebP, downsampled with Lanczos and compressed. The browser applies the lights on the unlit hemisphere.

## Clouds and ocean mask — Solar System Scope / INOVE

- Provider and terms: <https://www.solarsystemscope.com/textures/>
- License: Creative Commons Attribution 4.0 International, <https://creativecommons.org/licenses/by/4.0/>.
- Cloud source (8192×4096): <https://www.solarsystemscope.com/textures/download/8k_earth_clouds.jpg>
- Immutable download mirror: <https://raw.githubusercontent.com/Siqister/files/2ed70f6955b88070080e21067568c233a50856ec/8k_earth_clouds.jpg> (same attributed Solar System Scope texture).
- Specular/ocean-mask source (2048×1024): <https://www.solarsystemscope.com/textures/download/2k_earth_specular_map.jpg>
- Credit: Solar System Scope / INOVE. The provider describes its Earth textures as NASA Blue Marble-derived composites with adjusted colours and saturation.
- Changes: cloud texture converted to grayscale, Lanczos downsampled to 2K/4K and WebP compressed; ocean mask converted to grayscale WebP. White is water, black is land. Cloud animation and lighting are website-created.

## Poster / fallback

`earth-poster.webp` is an original 1100×1100 orthographic rendering of the NASA
day map and the Solar System Scope cloud map, with website-created lighting and
an atmospheric rim. It is not a NASA full-disc photograph. No photograph is
being misrepresented as a live image.

## NASA usage

NASA's imagery and media guidelines: <https://www.nasa.gov/nasa-brand-center/images-and-media/>.
NASA imagery is generally not subject to copyright in the United States, but
the guidelines retain restrictions on logos, endorsement, identifiable people
and separately credited third-party works. These texture deliveries contain no
NASA logo, identifiable person or claim of NASA endorsement. NASA and source
scientists are credited above; Solar System Scope's CC BY attribution and change
notice are retained.

## Reproducibility

Run `python3 scripts/build-earth-assets.py` with Pillow 11.3.0. The builder only
downloads imagery when a required tier is missing; all normal visitors use
vendored files. `--export-generated` emits exact generated bytes for review in
read-only CI. `manifest.json` records each final file's dimensions, size and
SHA-256 hash. Data dates remain the source composite dates, not the current date.
