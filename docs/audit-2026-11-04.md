# Full site audit, 4 November 2026

Scope: every tracker and dated claim (fact-checked against primary sources), SEO, accessibility (WCAG 2.2 AA via axe), links, feeds, sitemap, live-site behaviour and the test suites. Method: three research agents fact-checked the data files in parallel (claim tables in `docs/audit-2026-11-04/facts-*.md`); the technical sweeps were run directly against the latest `main` (22e1a5ee) and the live site. Nothing in the site's data or pages was changed by this audit; every item below is a proposal.

Rules used: `CLAUDE.md`, `.claude/rules/editorial.md`. Anything that could not be verified is said so; "wrong" means a source contradicts it.

## Verdict

The site is in good shape. Every headline number that could be checked was right: Starship flights 1 to 14, every Starlink count (matches Jonathan McDowell's 2 Nov table to the digit), the launch board, Tesla Q3 production and deliveries (464,391 / 486,532, matching the 8-K), all 187 EPA records, FSD subscriptions and European approvals, the Roadster facts, Grok model data. No weekday/date mismatch in 88 files. No source URL returned a true 404 (403s are bot walls).

What needs fixing is a short list: one wrong time zone in an article, a stale status label on five robotaxi cities, a stale promise ledger, dead SpaceX source links, one accessibility failure that affects every page, a handful of SEO items and a few internal contradictions.

## 5. Tests and build

- `node --test tests/*.test.mjs`: 382 of 383 pass; `js-bundle-build` fails only because esbuild is not installed in this environment (CI has it).
- `python3 -m unittest`: 2 failures. (a) `test_astro_scaffold`: two files exceed the 25 MiB Cloudflare Workers asset limit: `assets/video/tesla-the-plan-720.mp4` (79.6 MiB) and `assets/dispatch/raptor-film-720p.mp4` (27.9 MiB). This matters for the Astro/Cloudflare migration, not for GitHub Pages. Host them elsewhere (R2/Stream) or compress. (b) `test_render_article.test_no_x_assets_without_a_post`: the renderer now adds `x-embed.js`/`.css` to a page whose only X mention is a plain link; either the test fixture or the "uses X" heuristic is stale. Check whether CI's render checks run this test.
- Deployments: the pages build and the bot refreshes (launches, Starlink, Robotaxi, updates, news) are succeeding on `main`.

## 6. Live-site headers (owner/Cloudflare settings)

Only `x-content-type-options` and a 30-day HSTS are sent. Missing: Content-Security-Policy, X-Frame-Options (or frame-ancestors), Referrer-Policy, Permissions-Policy; HSTS could be 1 year with preload. There is no web app manifest (needed for the planned installable app). HTML is cached for 10 minutes.
